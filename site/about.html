About OrbitNet

OrbitNet is a collection of free online tools for networking, development, electronics, mathematics, and everyday tasks. The goal is simple: useful tools that are easy to access, straightforward to use, and free from unnecessary clutter.

No accounts, no subscriptions, no nonsense.

How the tools work

OrbitNet uses two approaches, depending on the tool.

Browser-based tools run directly on your device. Your input stays in your browser, and no server request is needed to perform the calculation.

Server-based tools send requests to the OrbitNet backend when they need access to network information or services that a browser cannot access directly. These requests are processed by the server, and limited technical information may appear in server logs.

Privacy

OrbitNet is designed to collect as little data as possible. There are no accounts, no analytics scripts, and no advertising trackers.

Browser-based tools

Most tools run entirely in your browser. Inputs such as text, numbers, colors, and passwords are processed locally and are not transmitted to the server.

Server-based tools

Tools that need network information send only the request required for that lookup. This may include the hostname, IP address, email, or DNS selector you ask about. Results are not stored in a database; some may remain in short-lived in-memory caches for up to an hour.

External fallback

If a local network check is blocked or cannot complete, the backend may retry that one check through a Cloudflare Worker. The Worker may contact the target site and public DNS-over-HTTPS resolvers (Cloudflare, Google, AdGuard). Only the host or IP being checked is sent this way; ordinary successful checks stay on the OrbitNet backend.

Logs and retention

Caddy keeps a sanitised request log for up to 7 days with the path but without IP addresses, headers, or query strings. nginx access logging and backend per-request logging are disabled. Docker logs are size-capped and used only for diagnostics. Lookup results are not used to build profiles and are not sold or shared for advertising.

Local storage

The home page can remember your favorite tools in your browser's local storage. This stays on your device and is not sent to the server. Clearing site data removes it.

Your choices

Each tool works a little differently, so check what it does before sending sensitive information. If you do not want a request to reach the server, use a browser-based tool or self-host OrbitNet. The full policy, including third parties and your rights, is on the Privacy page.
