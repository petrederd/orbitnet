JWT Decoder

Decode the header and payload of a JSON Web Token. Everything runs locally in your browser — the token is never sent anywhere.

Token

Result

Paste a token and click Decode

Important

  • Decoding is not verification: the signature is not checked and no key is used.
  • The payload is only base64url-encoded, so treat token contents as readable. Tokens may contain sensitive data.
  • This decoder never transmits the token — it is processed entirely in your browser.
