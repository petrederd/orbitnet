Redirect Generator

Build redirect rules for nginx or Apache from a simple list. Use old -> new per line, with an optional status code.

Rules

old -> new [code]. A trailing * creates a wildcard rule; $1 receives the remaining path.

Config snippet

Examples

/old -> /new /docs/* -> https://docs.example.com/$1 http://example.com/legacy -> https://example.com/new 308

nginx exact rules use location = and return; wildcard rules use rewrite so the suffix is not taken from a decoded return capture. Apache uses RedirectMatch for both exact and wildcard paths.

Source and target values reject control characters, quotes, backslashes, $ (except the wildcard $1 placeholder), braces and semicolons. Regex metacharacters in the source path are escaped automatically. nginx wildcard rules support 301 and 302; use Apache for wildcard 307/308.

Always test redirects in a staging environment. Avoid redirect chains, and use 301/308 only when the move is permanent.
