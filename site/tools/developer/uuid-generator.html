What is a UUID?

AUUID (Universally Unique Identifier) is a 128-bit number used to uniquely identify information. The probability of generating duplicate UUIDs is negligibly small.

UUID Format

Standard UUID format:xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx

  • Version 4: Random UUIDs (used by this generator)
  • 128 bits: 32 hexadecimal digits (0-9, a-f)
  • 5 groups: Separated by hyphens (8-4-4-4-12)

Common uses

  • Database primary keys: Unique IDs for records
  • API request tracking: Trace requests across systems
  • Session IDs: Identify user sessions
  • File naming: Ensure unique filenames
  • Testing: Generate test data

Security note

UUIDs are generated using the browser'scrypto.randomUUID() API, which uses a cryptographically secure random number generator. UUIDs are not secret tokens and should not be used for authentication or security purposes alone.
