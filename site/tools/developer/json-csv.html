JSON to CSV Converter

Turn an array of JSON objects into CSV. Nested objects can be flattened into dotted column names, and arrays are kept as compact JSON strings.

How values are handled

  • Objects are flattened with dots: {"meta":{"active":true}} becomes meta.active.
  • Arrays and nested objects that are not flattened are serialized as JSON strings inside the cell.
  • null becomes an empty cell; booleans and numbers use their JSON text.
  • Fields containing commas, quotes or newlines are quoted and embedded quotes are doubled, as required by RFC 4180.
  • With formula protection enabled, string cells beginning with =, +, -, @, tab or carriage return get a leading apostrophe. Numbers, booleans and numeric strings such as -5 are left unchanged, so negative values stay numeric.
  • Numbers are parsed with JSON.parse, which uses IEEE-754 doubles. Integers above 2^53-1 can lose precision, and 1.0 is indistinguishable from 1.
