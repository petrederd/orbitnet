What is Base64?

Base64 is an encoding scheme that converts binary data into ASCII text. It's commonly used to:

  • Embed images in HTML/CSS (data:image/png;base64,...)
  • Encode credentials for HTTP Basic Authentication
  • Store binary data in JSON or XML
  • Safely transmit data through systems that only support text
  • Encode email attachments (MIME)

How it works

Base64 uses 64 characters (A-Z, a-z, 0-9, +, /) to represent data. Every 3 bytes of input becomes 4 characters of output, increasing size by ~33%.

Important notes

  • Not encryption: Base64 is encoding, not encryption. Anyone can decode it.
  • Privacy: All encoding/decoding happens in your browser. Data is never sent to any server.
  • URL-safe variant: Replace + with - and / with _ for URL-safe Base64

Example

Text: Hello, World!
Base64: SGVsbG8sIFdvcmxkIQ==
