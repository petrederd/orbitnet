How the comparison works

  • Objects are compared by key, so changing key order produces no differences.
  • Arrays are compared by index. Inserting an item in the middle therefore shifts later indices.
  • Types matter: 1, "1", true and null are different values.
  • JSON paths use $ for the root, dots for identifiers and brackets for other keys or array indices.
  • Number precision: both sides are parsed with JSON.parse, so numbers use IEEE-754 doubles. Integers above 2^53-1 may compare equal after rounding, and 1.0 compares equal to 1.
