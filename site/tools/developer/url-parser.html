URL Parser

Break a URL into its components and inspect query parameters as a table. Duplicate keys are preserved, and values are decoded for readability.

URL

A missing https:// scheme is added automatically for convenience.

Components

Enter a URL to parse it.

What gets parsed

The tool uses the browser's built-in URL parser, so it follows the same rules as fetch() and new URL(). It shows the normalized URL, origin, credentials, host and port separately, plus path segments and every query parameter.

Query values are decoded once. If the same key appears multiple times, each occurrence gets its own row. The original query string is shown separately for debugging.
