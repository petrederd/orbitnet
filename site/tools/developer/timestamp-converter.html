Seconds or milliseconds?

Unix time counts seconds since 1 January 1970 UTC. Many languages and tools use milliseconds instead, which is 1000× larger. Auto-detect treats values with an absolute value of 1e11 or more as milliseconds. Negative values with an absolute value of 1e7 or more are also treated as milliseconds, so dates just before 1970 work correctly. ISO 8601 strings such as 2026-01-01T12:00:00Z are parsed directly.
