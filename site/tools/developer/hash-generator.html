About hashing

A cryptographic hash turns any input into a fixed-length fingerprint. Identical input always produces the same hash, and even a tiny change produces a completely different result. MD5 and SHA-1 are considered broken for security purposes but remain useful for checksums; use SHA-256 or stronger for anything security-related.
