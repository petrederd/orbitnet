YAML ↔ JSON Converter

Convert configuration between YAML and JSON without sending it anywhere. The YAML side uses the standard js-yaml parser with the default schema.

YAML

JSON

Notes

  • Conversion happens entirely in your browser. No configuration is uploaded.
  • YAML anchors, custom tags and comments are not preserved when converting to JSON.
  • JSON numbers keep their numeric value, but formatting such as 1.0 or 1e3 is normalized by the parser.
  • Number precision: both parsers use IEEE-754 doubles. Integers above 2^53-1 can lose precision, and 1.0 is indistinguishable from 1.
  • Duplicate mapping keys are rejected by the YAML parser instead of silently overwriting one another.
