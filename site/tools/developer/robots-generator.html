robots.txt Generator

Create a clean robots.txt for your site. Add user-agent rules, allow/disallow paths, an optional crawl delay and a sitemap URL.

Rules

Use * for all crawlers, or comma-separated bot names such as Googlebot, Bingbot. Multiple names share the rules below.
Add full robots.txt groups with their own User-agent, Allow, Disallow, Crawl-delay or Sitemap lines.

robots.txt

Remember

  • robots.txt is a voluntary convention, not an access control mechanism. It does not protect private data.
  • Rules are matched by path prefix. Disallow: /admin/ blocks that directory, but not /admin without a trailing slash.
  • Use the most specific Allow rule to reopen a path inside a blocked directory.
  • Keep the file at the site root: https://example.com/robots.txt.
  • An empty Disallow: line explicitly allows everything for its user-agent group. Use the checkbox to add it.
  • Use the additional-groups box for crawlers that need different rules from the main group.
