URL Encoder & Decoder

Convert text to percent-encoded form and back. Use component mode for query values, or full-URI mode when you want to keep URL separators such as / and ? intact.

Input

Component mode encodes separators like /, ? and &. Full URI mode keeps them.

Output

Which mode should I use?

  • Component — for a single query parameter, path segment or form value. It encodes &, =, /, ? and spaces.
  • Full URI — for a complete URL. It leaves structural characters alone, but still encodes spaces and non-ASCII text.

Decoding is strict: malformed percent sequences such as %ZZ or incomplete UTF-8 are rejected instead of being silently changed.
