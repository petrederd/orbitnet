Network Diagnostics

Resolve a hostname or IP, read its forward and reverse DNS and test a TCP port — a single page combining the basic network checks.

Target

Result

Enter a target and click Run

Checks performed

  • Your IP — the public IP our server sees for your connection.
  • Forward DNS — A and AAAA records of the target.
  • Reverse DNS — PTR of the target IP, if one exists.
  • TCP port — whether a TCP connection is accepted.

Port checks are only performed against public addresses. A closed port may also mean a firewall silently drops the packet.
