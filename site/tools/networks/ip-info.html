About this tool

Enter an IP address or a domain name. For a domain we resolve its DNS records and use the first public address for the geolocation and whois sections. Lookups normally run on our own server; if local DNS is blocked, an external checker may be used.

What each value means

  • Geolocation & provider:
    • Location: approximate city, region and country the address is registered to.
    • Provider: the organisation (ISP or hosting company) and its autonomous system number (ASN).
    • Timezone: time zone associated with the detected location.
    • Coordinates / Accuracy radius: approximate latitude and longitude, plus how far off the estimate may be.
  • DNS records:
    • A / AAAA: IPv4 and IPv6 addresses the name points to.
    • MX: mail servers with their priority (lower is preferred).
    • NS: authoritative name servers for the zone.
    • TXT: free-form text records (SPF, verification tokens, etc.).
    • Reverse DNS (PTR): for an IP address, the hostname registered for it.
  • Whois registration: registrar, creation/expiry dates, status and nameservers as published by the registry, followed by the full raw response.
