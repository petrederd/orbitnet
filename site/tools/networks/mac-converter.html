MAC Address Converter

Convert a MAC address between the common formats and inspect its address type and OUI prefix.

Input

Separators (:, -, .) are optional and case does not matter.

Result

Enter a MAC address to convert.

Reading a MAC address

  • OUI — the first 3 bytes identify the vendor that registered the address.
  • I/G bit — the least significant bit of the first byte: 0 = unicast, 1 = multicast/broadcast.
  • U/L bit — the second least significant bit of the first byte: 0 = globally unique (vendor), 1 = locally administered.
