IPv6 Converter

Convert an IPv6 address between compressed and fully expanded forms, and inspect its hextets, 128-bit decimal value, binary representation and reverse-DNS name.

Address

Accepts compressed, expanded and IPv4-mapped forms. Zone IDs such as %eth0 are ignored.

Formats

Enter an IPv6 address to convert it.

IPv6 notation

  • Leading zeros in each 16-bit group can be removed: 2001:0db8 becomes 2001:db8.
  • One run of zero groups can be replaced with ::. The longest run is preferred; ties go to the first run.
  • An IPv4-mapped address such as ::ffff:192.0.2.1 is converted to hexadecimal groups for calculations.
  • The reverse-DNS name is built from the 32 hexadecimal nibbles in reverse order under ip6.arpa.
