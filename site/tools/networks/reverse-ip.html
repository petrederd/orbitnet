Reverse IP Lookup

Find the hostname associated with an IP address through its PTR (reverse DNS) record. Resolved by our own server.

Input

If you enter a domain, it is resolved to its IP addresses first.

Result

Enter an IP address or domain.

What is reverse DNS?

Forward DNS maps a name to an IP address. Reverse DNS does the opposite: it looks up the PTR record for an address to find which hostname points to it. Not every IP has a PTR record, and the name it returns is controlled by the network owner, so it should not be treated as authoritative.
