IPv6 Subnet Calculator

Calculate an IPv6 network from an address and prefix length. The tool expands and compresses the result and counts the addresses in the subnet.

Subnet

0–128. For example, /64 is the standard LAN prefix.

Results

Enter an IPv6 address and prefix.

IPv6 subnetting notes

  • IPv6 has no broadcast address. The first address is the network address and the last address is the final address in the range.
  • A /64 provides 264 addresses, which is the normal size for a single LAN.
  • Zone identifiers such as %eth0 are ignored when parsing.
  • IPv4-mapped addresses such as ::ffff:192.0.2.1 are supported.
