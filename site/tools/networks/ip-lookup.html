About this tool

This tool shows your public IP address — the address that websites and online services see when you connect to them. This is different from your local/private IP address used within your home or office network. All lookups run on our own server using the MaxMind GeoLite2 databases, so no third-party geolocation service sees your request.

What each value means

  • IP address: your public IPv4 or IPv6 address.
  • IP version: whether the address is IPv4 or IPv6.
  • Reverse DNS: the PTR hostname registered for the address, if any. It is often missing for home connections.
  • Location: the city, region and country the address is registered to. It is approximate and usually points at your provider, not your exact street.
  • Provider: the organisation that owns the address (your ISP or hosting company) and its autonomous system number (ASN), e.g. AS15169.
  • Timezone: the time zone associated with the detected location.
  • Coordinates: approximate latitude and longitude of the location (opens in OpenStreetMap).
  • Accuracy radius: how far from the coordinates the real location may be, in kilometres.
  • Country code: the two-letter ISO country code (e.g. US, DE).

Privacy note

OrbitNet does not build or store user profiles. Like any web service, the server and reverse proxy may keep standard technical access logs (for example, IP address and request time). To inspect any other IP address or domain, use the IP & Domain Info tool.

This product includes GeoLite2 data created by MaxMind, available from https://www.maxmind.com.
