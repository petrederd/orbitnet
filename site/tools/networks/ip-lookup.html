About this tool

This tool shows your public IP address — the address that websites and online services see when you connect to them. This is different from your local/private IP address used within your home or office network.

Information displayed

  • IP Address: your public IPv4 or IPv6 address
  • IP version: whether the address is IPv4 or IPv6
  • Reverse DNS: the PTR hostname registered for the address, if any

Privacy note

No third-party geolocation service is used and no data is stored or logged by OrbitNet. To inspect any other IP address or domain, use the IP & Domain Info tool.
