DNS Propagation Checker

Compare the answers of several public DNS resolvers for one record. Useful after changing an A, MX or NS record.

How to read it

Each resolver is queried independently. If every resolver returns the same set of records, the change has propagated to the resolvers used here. Differences usually mean caches have not expired yet — wait for the previous record's TTL.
