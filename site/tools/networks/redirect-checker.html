Redirect Checker

Follow an HTTP redirect chain, showing every status code and the final destination. Handy when configuring redirects in Caddy or nginx.

Check

Result

Enter a host and click Trace

Notes

  • Only up to 10 hops are followed; a longer chain is reported as unsafe.
  • Redirects to private or non-public addresses are refused.
  • Prefer a single permanent redirect (301) to HTTPS instead of long chains — each hop adds latency.
