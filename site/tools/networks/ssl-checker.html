SSL/TLS Checker

Inspect a server's TLS certificate: validity period, issuer, subject alternative names, certificate chain and hostname match.

Check

Default 443. Allowed ports: 443, 465, 993, 995, 8443.

Result

Enter a host and click Check

What is checked

  • Validity: certificate not-before / not-after dates and days remaining.
  • Trust: whether the certificate chains to a trusted root.
  • Hostname match: the certificate must cover the requested host (CN or SAN).
  • Chain: the certificates sent by the server, up to the root.

The TLS handshake is performed by our server so the connection only ever goes to the resolved public IP of the host you entered.
