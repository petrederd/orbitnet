SSL/TLS Checker

Inspect a server's TLS setup: certificate validity, issuer, SANs and chain, plus supported protocol versions, cipher suites, OCSP stapling and CAA records.

Check

Default 443. Allowed ports: 443, 465, 993, 995, 8443.
Probes supported TLS versions and cipher suites, OCSP stapling and CAA records.

Result

Enter a host and click Check

What is checked

  • Validity: certificate not-before / not-after dates and days remaining.
  • Trust: whether the certificate chains to a trusted root.
  • Hostname match: the certificate must cover the requested host (CN or SAN).
  • Chain: the certificates sent by the server, up to the root.
  • Protocols & ciphers (deep scan): which TLS versions and cipher suites the server accepts, with weak ones flagged.
  • OCSP stapling: whether the server attaches a signed OCSP response to the handshake.
  • CAA records: which certificate authorities are allowed to issue for the domain (RFC 8659).

The TLS handshake is performed by our server so the connection only ever goes to the resolved public IP of the host you entered. Legacy protocols and ciphers that our own OpenSSL refuses to offer are reported as “not verifiable” rather than “rejected”.
