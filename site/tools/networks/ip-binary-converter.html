How IPv4 maps to numbers

An IPv4 address is four bytes (32 bits). Each dotted octet is one byte, so 192.168.1.1 becomes the 32-bit binary value 11000000.10101000.00000001.00000001, the integer 3232235777 or the hexadecimal 0xC0A80101.
