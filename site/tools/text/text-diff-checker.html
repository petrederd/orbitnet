Text Diff Checker

Compare two blocks of text line by line. Added lines are highlighted green, removed lines red, with a summary of changes.

Changed

Diff

How the comparison works

The tool uses a longest-common-subsequence algorithm to align the two texts, then marks lines that were added, removed or kept. It works line by line, so a small edit inside a line shows as one removed and one added line. All comparison runs in your browser.
