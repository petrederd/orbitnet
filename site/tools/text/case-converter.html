Case Converter

Change the letter case of any text: UPPERCASE, lowercase, Title Case, Sentence case, camelCase, snake_case, kebab-case, CONSTANT_CASE and more.

Available conversions

  • UPPERCASE / lowercase — every letter upper or lower
  • Title Case — first letter of every word capitalised
  • Sentence case — first letter of each sentence capitalised
  • camelCase / PascalCase — programming identifier styles
  • snake_case / kebab-case / CONSTANT_CASE — common code naming conventions
  • aLtErNaTiNg — alternating case

All processing happens in your browser. Nothing is uploaded.
