Statistics Calculator

Enter a list of numbers to get count, sum, mean, median, mode, variance, standard deviation and quartiles.

Data set

Separate values by commas, spaces or new lines. If you use a decimal comma, separate values with semicolons (e.g. 3,5; 7) or put a comma in every space-separated value (3,5 4,2).

Results

Enter some numbers to see statistics.

Formulas

  • Mean — the arithmetic average (sum ÷ count)
  • Median — the middle value of the sorted data
  • Variance — population divides by n, sample divides by n − 1
  • Standard deviation — the square root of the variance
  • Quartiles — Tukey's method: the median of the lower and upper halves, excluding the middle value for odd-sized sets (Q1, Q3); IQR = Q3 − Q1. Excel's QUARTILE.INC may return different values.
