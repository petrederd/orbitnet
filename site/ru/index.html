Частые вопросы

Инструменты бесплатны?
Да. Все инструменты бесплатны, не требуют аккаунта и не имеют ограничений на использование.
Вы храните введённые данные?
Нет. Большинство инструментов работает целиком в вашем браузере. Инструменты, которым нужны сетевые данные — IP, DNS или HTTP-проверки, — отправляют только запрос, необходимый для этой проверки. Результаты не хранятся в базе данных; недолговечные кэши в памяти могут держать их до часа. Подробности — на странице Конфиденциальность.
Можно ли развернуть OrbitNet самостоятельно?
Да. Исходный код опубликован на GitHub. Статический сайт можно разместить на любом веб-сервере, а API при необходимости запускается отдельным сервисом.
