О таймере 555

NE555 — одна из самых популярных интегральных микросхем в истории. Она может работать в двух основных режимах:

Автоколебательный режим (генератор)

Генерирует непрерывный прямоугольный сигнал. Идеально для:

  • Мигающие светодиоды и индикаторы
  • Генераторы тактового сигнала
  • Генераторы тона и зуммеры
  • Генерация ШИМ-сигнала

Формулы:

Frequency = 1.44 / ((R1 + 2×R2) × C)

Duty Cycle = (R1 + R2) / (R1 + 2×R2) × 100%

Схема подключения выводов в автоколебательном режиме

+Vcc (4.5-15V)
|
+---------------+---+---+---------------+
| | | |
| [R1] Pin 8 (Vcc) [10nF] (bypass cap)
| | | |
| Pin 4 ---+ +-------+ |
| (Reset) | | GND
| | NE555 |
Pin 7 ---+---[R2]---+ +--- Pin 3 (Output) -->Нагрузка
(Discharge) | | |
| +-------+
[C] | |
| +--- Pin 2,6 | Pin 1
GND (Trig,Thr) GND

Важно:Выводы 2 и 6 должны быть соединены вместе!
Вывод 4 (Reset) должен быть подключён к Vcc для нормальной работы.
Добавьте керамический конденсатор 10 нФ между выводом 5 (Control) и GND для стабильности.

Ждущий режим (одновибратор)

Выдаёт один выходной импульс при запуске. Используется для:

  • Подавление дребезга переключателей
  • Таймерные задержки
  • Растягивание импульса
  • Обнаружение пропущенных импульсов

Формула:

Pulse Width = 1.1 × R × C

Схема подключения выводов в ждущем режиме

+Vcc (4.5-15V)
|
+---------------+---+---+---------------+
| | | |
| [R] Pin 8 (Vcc) [10nF] (bypass cap)
| | | |
| Pin 4 ---+ +-------+ |
| (Reset) | | GND
| | NE555 |
Pin 7 ---+----------+ +--- Pin 3 (Output) -->Нагрузка
(Discharge) | | |
[C] +-------+
| Pin 6 |
+-- (Thr) Pin 1,5
GND GND
|
Trigger: Pin 2 ---[10kΩ]---+Vcc
| (pull-up)
[Button to GND]

Важно:Для вывода 2 нужен подтягивающий резистор (10 кОм) к Vcc.
Запуск по спадающему фронту (кратковременное подключение к GND).
Вывод 4 (Reset) к Vcc, вывод 5 к GND через конденсатор 10 нФ.

Советы по выбору компонентов

  • Резисторы: используйте значения от 1 кОм до 10 МОм. Больше значение = меньше потребление
  • Конденсаторы: керамические для высоких частот (>10 кГц), электролитические для низких (<10 Гц)
  • Скважность: стандартная автоколебательная схема не может дать ровно 50% (HIGH всегда длиннее, так как R1 > 0). Держите R1 малым относительно R2, чтобы приблизиться, или добавьте диод параллельно R2 для почти прямоугольной волны 50%
  • Точность: используйте резисторы с допуском 1% и качественные конденсаторы для точного тайминга
  • Питание: NE555 работает от 4,5–15 В. Используйте развязывающий конденсатор (10–100 нФ) рядом с выводом 8
  • Выход: вывод 3 может отдавать/принимать до 200 мА. Для светодиодов используйте токоограничивающий резистор
