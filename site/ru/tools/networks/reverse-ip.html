Обратный поиск IP

Найдите имя хоста, связанное с IP-адресом, через запись PTR (обратный DNS). Разрешается нашим сервером; если локальный DNS заблокирован, может использоваться внешняя проверка.

Ввод

Если вы введёте домен, сначала он разрешается в IP-адреса.

Результат

Введите IP-адрес или домен.

Что такое обратный DNS?

Прямой DNS сопоставляет имя с IP-адресом. Обратный DNS делает наоборот: ищет запись PTR для адреса, чтобы узнать, какое имя хоста на него указывает. Не у каждого IP есть запись PTR, а возвращаемое имя контролируется владельцем сети, поэтому его не стоит считать авторитетным.
