Проверка DNS для почты

Проверьте DNS-записи, благодаря которым работает почта домена: MX, SPF, DMARC, DKIM и PTR основного почтового сервера.

Проверить

Ищется как <selector>._domainkey.<domain>.

Результат

Введите домен и нажмите «Проверить»

Записи

  • MX — куда должна доставляться входящая почта для домена.
  • SPF — TXT-запись со списком серверов, которым разрешено отправлять почту от имени домена.
  • DMARC — TXT-запись в _dmarc, сообщающая получателям, как обрабатывать ошибки.
  • DKIM — публичный ключ в <selector>._domainkey, используемый для проверки подписанной почты.
  • PTR — обратный DNS для почтового сервера, используемый в проверках репутации.

Эти записи описывают только конфигурацию. Сами по себе они не гарантируют доставку почты.
