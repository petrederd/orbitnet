Диагностика сети

Разрешите имя хоста или IP, прочитайте прямой и обратный DNS и проверьте TCP-порт — одна страница с базовыми сетевыми проверками.

Результат

Выполненные проверки

  • Ваш IP — публичный IP, который наш сервер видит для вашего подключения.
  • Прямой DNS — записи A и AAAA цели.
  • Обратный DNS — PTR целевого IP, если он существует.
  • TCP-порт — принимается ли TCP-подключение.

Проверки портов выполняются только для публичных адресов. Закрытый порт также может означать, что файрвол молча отбрасывает пакет.
