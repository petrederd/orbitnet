Решение квадратных уравнений

Решайте квадратные уравнения вида ax² + bx + c = 0. Находите действительные и комплексные корни с пошаговыми деталями расчёта.

Параметры уравнения

ax² + bx + c = 0
Коэффициент при x² (не должен быть равен нулю)
Коэффициент при x
Свободный член

Решение

Введите коэффициенты и нажмите «Решить»

О квадратных уравнениях

Квадратное уравнение имеет вид ax² + bx + c = 0, где a ≠ 0.

Формула корней

x = (-b ± √(b² - 4ac)) / 2a

Дискриминант

D = b² - 4ac

  • D > 0: два различных действительных корня
  • D = 0: один корень (два равных корня)
  • D < 0: два комплексно-сопряжённых корня

Примеры

  • x² - 5x + 6 = 0 → a=1, b=-5, c=6 → x₁=3, x₂=2
  • x² - 4x + 4 = 0 → a=1, b=-4, c=4 → x=2 (двойной корень)
  • x² + x + 1 = 0 → a=1, b=1, c=1 → комплексные корни
