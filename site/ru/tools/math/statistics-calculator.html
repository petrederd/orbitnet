Калькулятор статистики

Введите список чисел, чтобы получить количество, сумму, среднее, медиану, моду, дисперсию, стандартное отклонение и квартили.

Набор данных

Разделяйте значения запятыми, пробелами или переводами строк. Если используете десятичную запятую, разделяйте значения точками с запятой (например, 3,5; 7) или ставьте запятую в каждом значении, разделённом пробелом (3,5 4,2).

Результаты

Введите числа, чтобы увидеть статистику.

Формулы

  • Среднее — среднее арифметическое (сумма ÷ количество)
  • Медиана — среднее значение упорядоченных данных
  • Дисперсия — для генеральной совокупности делится на n, для выборки — на n − 1
  • Стандартное отклонение — квадратный корень из дисперсии
  • Квартили — метод Тьюки: медиана нижней и верхней половин без среднего значения для наборов нечётного размера (Q1, Q3); IQR = Q3 − Q1. Функция Excel QUARTILE.INC может давать другие значения.
