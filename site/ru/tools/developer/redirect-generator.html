Генератор редиректов

Создавайте правила редиректов для nginx или Apache из простого списка. Указывайте old -> new по строке с необязательным кодом состояния.

Правила

old -> new [code]. Завершающая * создаёт правило с подстановочным знаком; $1 получает оставшуюся часть пути.

Фрагмент конфигурации

Примеры

/old -> /new /docs/* -> https://docs.example.com/$1 http://example.com/legacy -> https://example.com/new 308

Точные правила nginx используют location = и return; правила с подстановочными знаками используют rewrite, чтобы суффикс не брался из декодированного захвата return. Apache использует RedirectMatch и для точных, и для подстановочных путей.

Значения источника и цели не допускают управляющие символы, одинарные и двойные кавычки, обратные кавычки, обратные слеши, $ (кроме подстановки $1), фигурные скобки и точки с запятой. Метасимволы регулярных выражений в пути источника экранируются автоматически. Правила nginx с подстановочными знаками поддерживают 301 и 302; для 307/308 с подстановочными знаками используйте Apache.

Порядок в nginx: правила rewrite с подстановочными знаками выполняются на уровне server до выбора location. Если источник с подстановочным знаком является префиксом точного источника, подстановочное правило обработает запрос независимо от порядка в этом списке. Избегайте пересекающихся правил, размещайте точные пути под непересекающимся префиксом или используйте Apache для смешанных правил.

Всегда проверяйте редиректы в тестовой среде. Избегайте цепочек редиректов и используйте 301/308 только когда перенос окончательный.
