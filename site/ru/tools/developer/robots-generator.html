Генератор robots.txt

Создайте аккуратный robots.txt для своего сайта. Добавьте правила user-agent, разрешённые и запрещённые пути, необязательную задержку обхода и URL sitemap.

Правила

Используйте * для всех обходчиков или имена ботов через запятую, например Googlebot, Bingbot. Несколько имён используют указанные ниже правила.
Добавляйте полные группы robots.txt со своими строками User-agent, Allow, Disallow, Crawl-delay или Sitemap. Строки, начинающиеся с #, — комментарии.

robots.txt

Помните

  • robots.txt — добровольное соглашение, а не механизм контроля доступа. Он не защищает приватные данные.
  • Правила сопоставляются по префиксу пути. Disallow: /admin/ блокирует этот каталог, но не /admin без завершающего слеша.
  • Используйте наиболее конкретное правило Allow, чтобы снова открыть путь внутри заблокированного каталога.
  • Держите файл в корне сайта: https://example.com/robots.txt.
  • Пустая строка Disallow: явно разрешает всё для группы своего user-agent. Используйте галочку, чтобы добавить её.
  • Используйте поле дополнительных групп для обходчиков, которым нужны правила, отличные от основной группы.
