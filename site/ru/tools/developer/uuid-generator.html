Что такое UUID?

UUID (Universally Unique Identifier) — 128-битное число для уникальной идентификации информации. Вероятность появления одинаковых UUID пренебрежимо мала.

Формат UUID

Стандартный формат UUID:xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx

  • Версия 4: случайные UUID (используются этим генератором)
  • 128 бит: 32 шестнадцатеричные цифры (0-9, a-f)
  • 5 групп: разделены дефисами (8-4-4-4-12)

Частые применения

  • Первичные ключи баз данных: уникальные идентификаторы записей
  • Отслеживание API-запросов: трассировка запросов между системами
  • Идентификаторы сессий: распознавание пользовательских сессий
  • Имена файлов: гарантия уникальности имён
  • Тестирование: генерация тестовых данных

Примечание о безопасности

UUID генерируются с помощью API браузера crypto.randomUUID(), который использует криптографически стойкий генератор случайных чисел. UUID не являются секретными токенами и не должны использоваться для аутентификации или безопасности сами по себе.
