Конвертер YAML ↔ JSON

Преобразуйте конфигурацию между YAML и JSON, никуда её не отправляя. Для YAML используется стандартный парсер js-yaml со схемой по умолчанию.

Примечания

  • Преобразование полностью выполняется в браузере. Конфигурация никуда не загружается.
  • Якоря YAML, пользовательские теги и комментарии не сохраняются при преобразовании в JSON.
  • Числа JSON сохраняют числовое значение, но форматирование вроде 1.0 или 1e3 нормализуется парсером.
  • Точность чисел: оба парсера используют числа IEEE-754. Целые числа больше 2^53-1 могут потерять точность, а 1.0 неотличимо от 1.
  • Повторяющиеся ключи сопоставления отклоняются парсером YAML, а не перезаписывают друг друга молча.
