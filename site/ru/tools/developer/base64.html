Кодировщик и декодировщик Base64

Кодируйте текст в Base64 или декодируйте строки Base64 обратно в обычный текст. Подходит для передачи данных в URL, API и конфигурационных файлах.

Что такое Base64?

Base64 — схема кодирования, которая преобразует двоичные данные в ASCII-текст. Обычно используется для:

  • Встраивание изображений в HTML/CSS (data:image/png;base64,...)
  • Кодирование учётных данных для HTTP Basic Authentication
  • Хранение двоичных данных в JSON или XML
  • Безопасная передача данных через системы, поддерживающие только текст
  • Кодирование вложений электронной почты (MIME)

Как это работает

Base64 использует 64 символа (A-Z, a-z, 0-9, +, /) для представления данных. Каждые 3 байта входа превращаются в 4 символа выхода, увеличивая размер примерно на 33%.

Важные замечания

  • Это не шифрование: Base64 — кодирование, а не шифрование. Его может декодировать любой.
  • Приватность: всё кодирование и декодирование происходит в вашем браузере. Данные не отправляются ни на какой сервер.
  • URL-безопасный вариант: замените + на -, а / на _, чтобы получить URL-безопасный Base64

Пример

Текст:Hello, World!
Base64:SGVsbG8sIFdvcmxkIQ==
