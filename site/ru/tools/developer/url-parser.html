Разбор URL

Разбирает URL на компоненты и показывает параметры запроса в виде таблицы. Повторяющиеся ключи сохраняются, а значения декодируются для читаемости.

URL

Отсутствующая схема https:// добавляется автоматически для удобства.

Компоненты

Введите URL, чтобы разобрать его.

Что разбирается

Инструмент использует встроенный парсер URL браузера, поэтому следует тем же правилам, что fetch() и new URL(). Он отдельно показывает нормализованный URL, origin, учётные данные, хост и порт, а также сегменты пути и каждый параметр запроса.

Значения запроса декодируются один раз. Если один и тот же ключ встречается несколько раз, каждая пара получает свою строку. Исходная строка запроса показывается отдельно для отладки.
