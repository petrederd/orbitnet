Сравнение JSON

Сравнивает два JSON-документа по структуре, а не по порядку строк. Порядок ключей объекта не важен, а каждое изменение выводится с JSON-путём.

Как работает сравнение

  • Объекты сравниваются по ключам, поэтому изменение порядка ключей не даёт различий.
  • Массивы сравниваются по индексам. Поэтому вставка элемента в середину сдвигает последующие индексы.
  • Типы важны: 1, "1", true и null — разные значения.
  • В JSON-путях $ обозначает корень, точки — идентификаторы, а скобки — другие ключи и индексы массивов.
  • Точность чисел: обе стороны разбираются через JSON.parse, поэтому числа используют IEEE-754. Целые числа больше 2^53-1 после округления могут считаться равными, а 1.0 равно 1.
