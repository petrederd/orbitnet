Бесплатные онлайн-инструменты для разработчиков

Форматируйте, сравнивайте и конвертируйте данные без установки программ. Эти инструменты разработчика по возможности работают локально в браузере, поэтому введённые данные не покидают вашу машину.

Форматтер и валидатор JSON

Форматирует неаккуратный JSON, проверяет синтаксис и делает вложенные данные удобнее для чтения.

Сравнение JSON

Сравнивает два документа JSON по структуре и перечисляет добавленные, удалённые и изменённые значения.

Конвертер JSON в CSV

Разворачивает вложенные объекты JSON в CSV с настраиваемыми разделителями, заголовками и BOM.

Конвертер YAML ↔ JSON

Переводит конфигурацию между YAML и JSON локально с помощью парсера js-yaml.

Кодировщик и декодировщик Base64

Преобразует текст в Base64 и обратно, проверяет ввод и позволяет скопировать результат.

Кодировщик и декодировщик URL

Кодирует и декодирует компоненты URL и целые URI прямо в браузере.

Разбор URL

Разбирает URL на протокол, хост, путь, query и фрагмент и показывает таблицу параметров.

Генератор хешей

Вычисляет хеши MD5, SHA-1, SHA-256, SHA-384 и SHA-512 для любого текста.

Декодер JWT

Декодирует заголовок и полезную нагрузку JWT прямо в браузере и показывает его claims.

Генератор UUID

Генерирует уникальные идентификаторы для тестовых данных, разработки и быстрого прототипирования.

Генератор паролей

Создаёт надёжные случайные пароли и оценивает их устойчивость к перебору.

Тестер регулярных выражений

Проверяет регулярные выражения с флагами, подсветкой совпадений и разбором групп захвата.

Конвертер временных меток

Переводит между Unix-временем, ISO 8601 и понятными локальными датами и датами UTC.

Разбор cron-выражений

Объясняет cron-выражение из пяти полей простыми словами и показывает ближайшие запуски.

Конвертер цветов

Переводит цвета между HEX, RGB и HSL, с выбором цвета и предпросмотром.

Генератор редиректов

Создаёт правила редиректов для nginx или Apache .htaccess из простого списка «старый → новый».

Генератор robots.txt

Собирает robots.txt с разрешёнными и запрещёнными путями, задержкой обхода и URL карты сайта.

Очистка security-заголовков

Проверяет HTTP security-заголовки, находит слабые значения и создаёт аккуратный фрагмент конфигурации nginx.

JSON и преобразование данных

Проверяйте и форматируйте JSON, сравнивайте документы, разворачивайте вложенные объекты в CSV или конвертируйте YAML и JSON друг в друга.

Кодирование, хеширование и токены

Кодируйте и декодируйте Base64 и URL, считайте хеши MD5 и SHA, разбирайте claims JWT и генерируйте UUID или надёжные пароли.

Утилиты для веб-конфигурации

Проверяйте регулярные выражения, конвертируйте временные метки и цвета, разбирайте cron-расписания и создавайте правила редиректов или robots.txt.
