Frequently asked

Are the tools free?
Yes. Every tool is free, requires no account, and has no usage limits.
Do you store the data I enter?
No. Most tools run entirely in your browser. Tools that need network data, such as IP, DNS or HTTP checks, send only the request needed for that lookup, and results are not stored.
Can I self-host OrbitNet?
Yes. The source code is published on GitHub. The static site can be hosted on any web server, and the optional API runs as a separate service.
