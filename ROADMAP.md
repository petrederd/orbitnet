## Принципы дизайна

### Визуальный стиль
- **Темная тема по умолчанию** с оранжевым акцентом (#d46b15)
- **Геометрические формы** и четкие границы
- **Минимализм**: без лишних элементов
- **Читаемость**: крупные шрифты, контрастность

### UX принципы
1. **Мгновенная работа**: все инструменты работают в браузере
2. **Нет авторизации**: доступ без регистрации
3. **Клиент-сайд**: обработка данных локально (приватность)
4. **Копирование в один клик**: каждый результат можно скопировать
5. **Клавиатурные шорткаты**: `/` для поиска, `Esc` для сброса

### Технические требования
- Vanilla JavaScript (без фреймворков для простоты)
- Responsive дизайн (мобильные, планшеты, десктоп)
- Accessibility (ARIA-метки, семантичный HTML)
- SEO-friendly (meta-теги, структурированные данные)
- Быстрая загрузка (<100KB для главной страницы)

##  Контрибуция

### Как добавить новый инструмент

1. **Планирование**
   - Определите проблему, которую решает инструмент
   - Проверьте, нет ли дубликатов
   - Создайте issue в GitHub с описанием

2. **Разработка**
   - Создайте HTML-страницу в соответствующей категории
   - Используйте общий CSS (или расширяйте его)
   - Напишите чистый, документированный JavaScript
   - Добавьте примеры использования

3. **Тестирование**
   - Проверьте на мобильных устройствах
   - Валидация входных данных
   - Обработка ошибок
   - Accessibility проверка

4. **Документация**
   - Добавьте описание на главную страницу
   - Обновите счетчики инструментов
   - Добавьте инструмент в соответствующую категорию

##  Долгосрочное видение

**OrbitNet** должен стать:
-  Справочником для специалистов (сети, электроника, разработка)
-  Образовательным ресурсом (с объяснениями формул)
-  Повседневным инструментом (быстрый доступ к калькуляторам)
-  Open-source примером (качественный код, документация)

### Ценности проекта
1. **Прозрачность**: весь код открыт
2. **Приватность**: данные не покидают браузер
3. **Качество**: каждый инструмент тщательно протестирован
4. **Простота**: минимум зависимостей, чистый код
5. **Доступность**: бесплатно, без рекламы, без трекинга
